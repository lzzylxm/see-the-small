[![SkillHub](https://img.shields.io/badge/SkillHub-see--the--small-blue)](https://skillhub.cn/skills/see-the-small)

**见微** is an AI-powered personal growth companion skill. Think of it as a warm, quiet observer that helps you capture daily clues, notice your own patterns, and gives you a "mirror of echoes" every week.

- 📝 **Daily Check-in**: Chat like with a friend, AI structures your reflection
- 📊 **Mood & Energy Tracking**: Emotional labels, energy levels, satisfaction scores
- 🔄 **Weekly Echo**: 7-day data summary + pattern recognition + growth comparison
- 🧠 **Pattern Insights**: AI discovers hidden patterns you'd miss on your own
- 🔒 **100% Local**: All data stays on your device

## 一句话介绍

## 一句话介绍

见微是一个 AI 驱动的个人成长陪伴技能。它不只是一个复盘工具——它像一个温暖安静的观察者，帮你捕捉每天的线索、看见自己的变化模式，并在每周给你一面"回声镜子"。

## 为什么需要见微？

大多数复盘工具的问题是：**你记录了，但没人帮你回顾。**

- 写日记的人很多，但能坚持看回去的人很少
- 复盘需要的是规律，不是意志力
- 成长最大的障碍不是不够努力，而是**看不见自己的变化**

见微解决的正是这个矛盾——**你只管每天聊两句，AI 帮你看见全局。**

## 三大成长支柱（V1.4）

| 支柱 | 含义 | 数据来源 |
|------|------|---------|
| **复盘** | 发生了什么？ | 每日复盘 + 日常对话捕捉 |
| **注意力** | 时间/精力去了哪里？ | 会话元数据自动记录 + 心流分享 |
| **执行力** | 说过的事做了吗？ | 意图→结果自然关联（不做任务管理） |

## 两种记录模式

- **仅定时复盘**（简单模式）：每天固定时间 AI 问、你答，3 分钟搞定
- **对话+定时复盘**（推荐）：日常聊天中 AI 默默捕捉线索 + 定时复盘补充，数据最完整

## 适用人群

- 想养成复盘习惯但坚持不下来的人
- 想"被看见"而不是"被管理"的成长者
- 对自我认知有元兴趣、想了解自己模式的人
- 正在经历变化期、需要一面镜子的人

## 隐私承诺

- 所有数据存储在用户本地，不经过第三方服务器
- 数据完全归用户所有，随时可以查看、导出、删除
- 不做用户画像分析，不用于任何商业目的

## 快速开始

### 通过 SkillHub CLI 安装

```bash
skillhub search see-the-small
skillhub install see-the-small --dir <你的 skills 目录>
```

### 手动安装

将 `SKILL.md` 放入你的 AI 平台 skills 目录：

| 平台 | 目录 |
|------|------|
| WorkBuddy | `~/.workbuddy/skills/见微/` |
| QClaw / OpenClaw | `~/.openclaw/skills/见微/` |
| Claude Code | `~/.claude/skills/见微/` |
| Cursor | `~/.cursor/skills/见微/` |

### 配置定时复盘

安装后，告诉你的 AI：
> "帮我设置每天早上/晚上 X 点自动复盘"

不同平台的配置方式：
- **WorkBuddy**：创建自动化，每日触发，prompt 为"该复盘了"
- **QClaw/OpenClaw**：使用平台的 cron 定时任务
- **其他平台**：参考平台文档设置定时触发
